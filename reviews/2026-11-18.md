**任意**
- 説明問題の答えに、キーボードが出たあとの話を足すと、問いに最後まで答えられる。キーボードが出ると Keyboard Layout Guide の上端だけが上がり、2本の制約が別々の位置を求めるため、両方を同時に満たせなくなる。
- `tag` の数字（可読性）。MessageCardViewController.swift:31 の `2` は「最後の入力欄」という意味で、XIB の tag を変えると動きが変わる。outlet と比べると、どの欄の次がどの欄かがコードに書かれる。

```swift
func textFieldShouldReturn(_ textField: UITextField) -> Bool {
    if textField === toField {
        fromField.becomeFirstResponder()
    } else if textField === fromField {
        messageField.becomeFirstResponder()
    } else {
        view.endEditing(true)
        previewLabel.text = "\(toField.text ?? "")さんへ：\(messageField.text ?? "")（\(fromField.text ?? "")より）"
    }
    return true
}
```
