## 改善すべき点
**必須**
- StampCardViewController.xib:53 と :49。「スタンプを押す」と「リセット」の中央揃えが、Safe Area ではなく親ビュー（`i5M-Pr-FkT`）の `centerX` を基準にしている。課題の「XIB の制約」は Safe Area の横方向の中央を指定している（動作）。

**任意**
- `final` と `private`（Swiftらしさ）。StampCardViewController.swift:10 に `final`、:11 の `card` と :30 の `updateLabel()` に `private` を付けられる。`card` が外から書き換えられると、`addStamp()` の上限の判定を通らずに `stampCount` を変えられてしまう。

```swift
final class StampCardViewController: UIViewController {
    private var card = StampCard(stampCount: 0, goal: 10)

    private func updateLabel() {
        countLabel.text = "スタンプ：\(card.stampCount)/\(card.goal)"
    }
}
```

- 使っていない定数（可読性）。StampCardViewController.swift:12 の `spacing` はどこからも使われていない。余白は XIB で 16 を指定しているので、残すと「コードでも余白を決めている」と読み手が探してしまう。行ごと消すと読む量が減る。
