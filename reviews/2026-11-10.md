2. 【必須・動作】SceneDelegate.swift:19 で、BookViewController を `BookViewController()` で作っています。課題文では、XIB の名前を指定した `init(nibName:bundle:)` で作ることになっています（途中でお伝えした項目です）。
3. 【必須】説明問題にまだ答えていません。
4. 【任意・可読性】BookDetailViewController.swift:30-34 の extension の `bookDetailViewController(_:didSave:)` は、どこからも呼ばれていません。デリゲートの関数の中身は受け取る側（BookViewController.swift:35-40）に書くので、BookDetailViewController には要りません。使われないコードは「この画面も受け取る側なのか」という読み違いを生むので、実務では見つけたら消します。
5. 【任意・Swiftらしさ】継承しないクラスには `final`、外から触らないプロパティには `private` を付けると、意図が伝わります。
   ```swift
   final class BookDetailViewController: UIViewController {
       @IBOutlet private weak var titleLabel: UILabel!
       @IBOutlet private weak var isFinishedSwitch: UISwitch!
       weak var delegate: BookDetailViewControllerDelegate?
       var bookTitle = ""
       var isFinished = false
   ```
6. 【任意・可読性】BookViewController.swift:31 は、文字列の中に三項演算子が入っています。分岐を先に定数にすると、文字列の部分は並べるだけになります。
   ```swift
   private func updateLabel() {
       let status = book.isFinished ? "読み終えた" : "まだ読んでいない"
       bookLabel.text = "\(book.title)：\(status)"
   }
   ```
7. 【任意・動作】BookViewController.xib で、ラベルの幅 270 とボタンまでの間隔などがすべて固定です。合計がちょうど 393pt なので、横向きや小さい端末では制約がぶつかる見込みです（実行ログは未確認）。ラベルの幅の固定をやめて、ラベルとボタンの間を「10pt 以上」の不等式にすると、余った幅をラベルが受け取ります。
