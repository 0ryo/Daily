# 11/20（金）料理教室の予約フォーム

> 名前・人数・メモを入力して予約する画面を、return キーで次の入力欄へ移れるようにし、入力を確かめてから予約します。

- 作業場所：`1120/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 1.5時間／パート2 30分
- パート1だけで提出してよいです。

## 守ること
- 入力欄の文字は、前後の空白・改行を除いてから変換・検証する
- 過去の課題のコードを見ずに作る（公式ドキュメントは見てよい）
- `!` `try!` `as!` `try?` を使わない（`@IBOutlet` の `!` は除く）
- 画面は XIB で作る。Main.storyboard には部品を置かない
- 確かめることは、iPhone のシミュレータでソフトウェアキーボードを出して試す（出ないときは、シミュレータのメニュー I/O > Keyboard > Toggle Software Keyboard）
- ブランチ `1120` で PR を作る（マージは不要）。予約に成功した画面のスクリーンショットを PR に貼る

## パート1：入力を確かめて予約する（1.5時間）

### 列挙型 `ReservationError`
予約を作れなかった理由です。`Error` に準拠させます。

- ケース：`invalidName`（名前が条件に合わない）、`invalidPeople`（人数が条件に合わない）

### 構造体 `Reservation`
料理教室の予約1件です。Codable は不要です。

| プロパティ | 型 | 意味 |
|---|---|---|
| `name` | String | 前後の空白・改行を除いた名前 |
| `people` | Int | 参加する人数 |
| `note` | String | 前後の空白・改行を除いたメモ。空でもよく、長さの決まりはない |

```swift
init(name: String, people: Int, note: String) throws
```
- 目的：入力された値を確かめて、条件に合うときだけ予約を作る
- 引数：`name` と `note` は、前後の空白・改行を除いていない入力欄の文字。`people` は、呼び出し元が Int に変換した人数
- 戻り値：なし（条件に合わないときは `ReservationError` を投げる）

1. **名前を確かめるとき**：前後の空白・改行を除いた名前が1〜20文字でなければ、`invalidName` を投げる
2. **人数を確かめるとき**：`people` が1〜4でなければ、`invalidPeople` を投げる

### 画面 `ReservationViewController`
予約の入力欄と、結果のラベルを並べた画面です。

- 部品（XIB）：`formStackView`（縦向きの UIStackView。間隔 16）
- `formStackView` の中身（上から）：`nameField`（UITextField。プレースホルダー「名前」）、`peopleField`（UITextField。「人数（1〜4）」）、`noteField`（UITextField。「メモ（任意）」）、`reserveButton`（UIButton。「予約する」）、`resultLabel`（UILabel。行数は 0）
- `peopleField` のキーボード：Numbers and Punctuation（return キーがあるもの）
- XIB の制約：`formStackView` は Safe Area の上端と左右の端から 16

1. **SceneDelegate の `scene(_:willConnectTo:options:)`**：`ReservationViewController()` を最初の画面にした UINavigationController を作る。作った UINavigationController を、window の `rootViewController` にする
2. **`viewDidLoad()`**：`title` を「料理教室の予約」にし、`resultLabel` を「名前と人数を入力してください」にする
3. **「予約する」を押したとき**：キーボードを閉じる。`peopleField` の文字を Int に変換し、`Reservation` を作る
4. **予約を作れたとき**：`resultLabel` を「田中さん 2名で予約しました」の形にし、3つの入力欄を空にする
5. **予約を作れなかったとき**：入力欄の文字は残し、`resultLabel` を、名前なら「名前は1〜20文字で入力してください」、人数（Int に変換できないときも）なら「人数は1〜4の数字で入力してください」にする。名前と人数の両方が条件に合わないときは、どちらのメッセージでもよい

### 確かめること
上から順に試します。

- [ ] 実行する → 「料理教室の予約」と「名前と人数を入力してください」が出る
- [ ] 名前に「  田中  」、人数に「 2 」を入れて「予約する」を押す → 「田中さん 2名で予約しました」が出て、3つの入力欄が空になる
- [ ] 名前を空白だけ、人数を「2」にして「予約する」を押す → 「名前は1〜20文字で入力してください」が出て、入力欄の文字が残る
- [ ] 名前を「田中」、人数を「5」にして「予約する」を押す → 「人数は1〜4の数字で入力してください」が出る

## パート2：return キーで次の入力欄へ移る（30分）

### 画面 `ReservationViewController`
return キーだけで、3つの入力欄を上から順に入力できるようにします。

- return キーの表示（XIB）：`nameField` と `peopleField` は「Next」、`noteField` は「Done」

1. **`textFieldShouldReturn(_:)`**：`nameField` なら `peopleField` を、`peopleField` なら `noteField` を入力中にし、`noteField` ならキーボードを閉じる

### 確かめること
パート1の続きとして試します。

- [ ] `nameField` をタップし、return キーを3回押す → カーソルが `peopleField`、`noteField` の順に移り、3回目でキーボードが閉じる

### 説明問題
人数の前後の空白を除く処理を入れずに、`peopleField` に「 2 」と入れて「予約する」を押すと、「人数は1〜4の数字で入力してください」が出るのはなぜか？
