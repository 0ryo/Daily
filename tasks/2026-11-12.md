# 11/12（木）ニックネームを、デリゲートで前の画面に返す

> 編集画面で入力したニックネームを、デリゲートでプロフィールの画面に返し、ラベルに出します。

- 作業場所：`1112/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 1.5時間／パート2 30分
- パート1だけで提出してよいです。11/10 と同じ仕組みを別の題材で作ります。できれば 11/10 のコードを開かずに書き、詰まったら開いてかまいません。

## デリゲートの3つの役割
デリゲートは、ある画面で決まったことを、別の画面に知らせる仕組みです。

- **渡す側**（NicknameEditViewController）：決まったニックネームを、自分のプロパティ `delegate` に入っている相手に知らせる。相手がどの画面かは知らない
- **受け取る側**（ProfileViewController）：知らされたニックネームでラベルを書き換える。NicknameEditViewController を作るときに、NicknameEditViewController の `delegate` に `self` を入れておく。`delegate` に入るのは、受け取る側のほう
- **約束**（プロトコル NicknameEditViewControllerDelegate）：受け取る側が `nicknameEditViewController(_:didSave:)` を持っている、という決まり

渡す側が受け取る側の型名を使わないので、受け取る側が別の画面に変わっても、NicknameEditViewController は変えずに使えます。

## 守ること
- `!` `try!` `as!` `try?` を使わない（`@IBOutlet` の `!` は除く）
- `nickname` を書き換えるのは ProfileViewController だけ。NicknameEditViewController は `delegate` で知らせる
- 画面は XIB で作る。SceneDelegate では `ProfileViewController()` で作ってよい
- ブランチ `1112` で PR を作る（マージは不要）

## パート1：ニックネームをデリゲートで返す（1.5時間）

### プロトコル `NicknameEditViewControllerDelegate`
NicknameEditViewController が、決めたニックネームを知らせる相手の決まりです。下のコードの ①〜④ を埋めて、自分のファイルに書きます。①〜④ の答えはチャットに書かなくてかまいません。

```swift
// 約束：NicknameEditViewController.swift の、クラスの外
protocol NicknameEditViewControllerDelegate: ① {
    func nicknameEditViewController(_ controller: NicknameEditViewController, didSave nickname: String)
}

// 渡す側：NicknameEditViewController のプロパティ
② var delegate: NicknameEditViewControllerDelegate?

// 受け取る側：ProfileViewController.swift の、クラスの外
extension ProfileViewController: ③ {
    func nicknameEditViewController(_ controller: NicknameEditViewController, didSave nickname: String) {
        // 受け取った nickname でラベルを更新する（下の ProfileViewController の nicknameEditViewController(_:didSave:) で説明します）
    }
}

// 受け取る側：「変更する」を押したときの処理の中。editViewController は作った NicknameEditViewController
editViewController.delegate = ④
```
- 目的：`nicknameEditViewController(_:didSave:)` は、「保存」で決めたニックネームを受け取る側に知らせる
- 引数：`controller` は知らせる側の画面（NicknameEditViewController の `self`）、`nickname` は決めたニックネーム
- 戻り値：なし

### 画面 `ProfileViewController`
最初の画面。ニックネームをラベルに出します。

- プロパティ：`nickname`（String?。まだ決めていないときは `nil`。初期値は `nil`）
- 部品：ニックネームのラベル、「変更する」ボタン

1. **起動したとき**：SceneDelegate で、ProfileViewController を最初の画面にした UINavigationController を window に入れる
2. **`viewDidLoad()`**：`title` を「プロフィール」にし、`updateLabel()` を呼ぶ
3. **`updateLabel()`**：`nickname` が `nil` なら「ニックネーム：未設定」、`nil` でなければ「ニックネーム：はなこ」の形でラベルに出す
4. **「変更する」を押したとき**：`NicknameEditViewController()` で作って定数 `editViewController` に入れ、`delegate` に `self` を入れて push する
5. **`nicknameEditViewController(_:didSave:)`**：`nickname` を受け取った値にし、`updateLabel()` を呼ぶ

### 画面 `NicknameEditViewController`
ニックネームを入力する編集画面です。

- プロパティ：`delegate`（NicknameEditViewControllerDelegate?。`weak var` で宣言する）
- 部品：入力欄（UITextField）、「保存」ボタン

1. **「保存」を押したとき**：`delegate` の `nicknameEditViewController(_:didSave:)` に、`self` と入力欄の文字列（`nil` なら空の文字列）を渡して呼び、pop で ProfileViewController に戻る

### 確かめること
上から順に試し、「はなこ」を保存して戻った画面のスクリーンショットを PR に貼ります。

- [ ] 実行する → 「プロフィール」と「ニックネーム：未設定」が出る
- [ ] 「変更する」 → 「はなこ」と入力 → 「保存」 → ラベルが「ニックネーム：はなこ」に変わる

## パート2：前後の空白を除き、空なら返さない（30分）

### 画面 `NicknameEditViewController`
- 部品を足す：誤りのラベル（XIB では空にしておく）

### 説明問題
ProfileViewController で `delegate` に `self` を入れる行を消し、「はなこ」と入力して「保存」を押すと、アプリは落ちずに画面が戻り、ラベルは変わらない。`delegate` が `nil` なのに、NicknameEditViewController が `delegate` の関数を呼ぶ行でエラーが起きないのはなぜか？
