# 11/8（日）作りたいレシピの一覧から、選んだレシピの詳細画面へ移る
- 作業場所：`1108/`（Xcode の iOS App プロジェクト。XIB + Auto Layout）
- 想定時間：6時間（パート1 約3.5時間、パート2 約2.5時間）
- パート1で、レシピの一覧の行をタップすると、タップした行のレシピの詳細画面が UINavigationController で表示されるようにします。パート2で、詳細画面に「一覧に戻る」ボタンを付け、UINavigationController のスタックに積まれた画面の件数を print で確かめます。UINavigationController は、表示した画面を順に重ねて持ちます。重ねて持っている画面の全体をスタックと呼びます。パート1が終わった時点で提出してよいです。パート2は、時間がなければ次の日に回してかまいません。

## 守ること（パート1・2 共通）
- `!`、`try!`、`as!`、`try?` を使わない（XIB の `@IBOutlet` の宣言の `!` は除く）。
- 「45分」のような時間の文字列は、Recipe の `cookingTimeText()`（1-1）でだけ作る。一覧の行と詳細画面の両方で、`cookingTimeText()` を呼んで使う。
- RecipeListViewController と RecipeDetailViewController は、どちらも XIB で作り、部品を XIB に置く。Main.storyboard には部品を置かない。
- ブランチ `1108` で、今日の `1108/` の変更だけで PR を作る（マージは不要）。

## パート1：一覧の行をタップして、詳細画面へ移る（約3.5時間）
### 構造体
**1. Recipe**（作りたいレシピ1件）
- プロパティ：
  - `name`（String、レシピの名前）
  - `cookingMinutes`（Int、作るのにかかる時間の分数）
  - `memo`（String、作るときのメモ）
  - `static let samples`（[Recipe]、一覧に最初に表示する3件。上から次の順にする）
    - カレー（45分、メモ「玉ねぎはあめ色になるまで炒める」）
    - オムライス（20分、メモ「卵は半熟で火を止める」）
    - 豚汁（30分、メモ「味噌は火を止めてから溶く」）
- 関数：
  - **1-1. `cookingTimeText() -> String`**
    - 目的：作るのにかかる時間を、画面に表示する文字列にする。
    - 引数：なし
    - 戻り値：「45分」の形の文字列
    - 処理：
      - **1-1-1.** `cookingTimeText` が、`cookingMinutes` の数字の後ろに「分」を付けた文字列を返す。
- 特記事項：エンコードとデコードは不要（今日はファイルに保存しない）。

### 画面
**2. RecipeListViewController**（レシピの一覧の画面。RecipeListViewController.xib）
- プロパティ：`recipes`（[Recipe]、一覧に表示するレシピ）
- **2-1. 部品**：UITableView を1つ、Safe Area いっぱいに置く。
- **2-2. 起動したとき**
  - **2-2-1.** SceneDelegate.swift の `scene(_:willConnectTo:options:)` で、RecipeListViewController を最初の画面にした UINavigationController を作り、window の `rootViewController` に入れる。11/4 の課題では `rootViewController` に HomeViewController をそのまま入れたが、今日は RecipeListViewController を UINavigationController で包んでから入れる。
  - **2-2-2.** RecipeListViewController が、`viewDidLoad()` の中で、`title` に「レシピ」を入れる。`title` に入れた文字は、ナビゲーションバーに表示される。
  - **2-2-3.** RecipeListViewController が、`viewDidLoad()` の中で、`recipes` に `Recipe.samples` を入れ、一覧に表示する。
- **2-3. 一覧の行**：1行に1件のレシピを「カレー：45分」の形で表示する。並び順は `recipes` の順にする。
- **2-4. 行をタップしたとき**（UITableViewDelegate の `tableView(_:didSelectRowAt:)`）
  - **2-4-1.** RecipeListViewController が、タップされた行の選択を解除する（行の灰色の表示を消す）。
  - **2-4-2.** RecipeListViewController が、タップされた行の Recipe を `recipes` から取り出し、RecipeDetailViewController の `init(recipe:)`（3-1）に渡して RecipeDetailViewController を作る。
  - **2-4-3.** RecipeListViewController が、自分の `navigationController` の `pushViewController(_:animated:)` で、作った RecipeDetailViewController を表示する。`animated` は `true` にする。`navigationController` が `nil` のときは何もしない。

**3. RecipeDetailViewController**（1件のレシピの詳細画面。RecipeDetailViewController.xib）
- プロパティ：`recipe`（Recipe、表示するレシピ。`let` で宣言する）
- **3-1. `init(recipe: Recipe)`**（下の「並べ替え問題」で作る）
  - 目的：表示するレシピを受け取って、XIB を使う RecipeDetailViewController を作る。
  - 引数：`recipe`（Recipe、表示するレシピ）
  - 戻り値：なし
  - 処理：
    - **3-1-1.** `init(recipe:)` が、引数 `recipe` を、プロパティ `recipe` に入れる。
    - **3-1-2.** `init(recipe:)` が、XIB の名前「RecipeDetailViewController」を指定して、親クラス（UIViewController）の `init(nibName:bundle:)` を呼ぶ。
- **3-2. 部品**：時間のラベルと、メモのラベル（複数行で表示できるようにする）を置く。
- **3-3. 画面を読み込んだとき**（`viewDidLoad()`）
  - **3-3-1.** RecipeDetailViewController が、`title` に `recipe` の `name` を入れる。
  - **3-3-2.** RecipeDetailViewController が、時間のラベルに「かかる時間：」と、`recipe` の `cookingTimeText()`（1-1）の結果をつないで表示する。
  - **3-3-3.** RecipeDetailViewController が、メモのラベルに `recipe` の `memo` を表示する。

### 並べ替え問題
RecipeDetailViewController の `init(recipe:)` と、XIB を使う画面をコードだけで作るときに必要な `init?(coder:)` です。
下の行を正しい順に並べて、RecipeDetailViewController の中に置いてください。クラスの中に置くので、全体を1段下げます。2つのイニシャライザは、どちらを先に置いてもかまいません。行の追加と削除はしません。

```swift
    fatalError("init(coder:) は使いません")
}
    super.init(nibName: "RecipeDetailViewController", bundle: nil)
required init?(coder: NSCoder) {
    self.recipe = recipe
init(recipe: Recipe) {
}
```

## 参考
### 公式ドキュメント
- [UINavigationController](https://developer.apple.com/documentation/uikit/uinavigationcontroller)：画面をスタックに積んで、一覧から詳細へ移る仕組みの全体（2-2-1、2-4-3、説明問題2）。
- [init(rootViewController:)](https://developer.apple.com/documentation/uikit/uinavigationcontroller/init(rootviewcontroller:))：最初の画面を決めて UINavigationController を作る方法（2-2-1）。
- [rootViewController](https://developer.apple.com/documentation/uikit/uiwindow/rootviewcontroller)：アプリを起動したときに最初に表示する画面を決めるプロパティ（2-2-1）。
- [title](https://developer.apple.com/documentation/uikit/uiviewcontroller/title)：ナビゲーションバーに表示される画面の名前（2-2-2、3-3-1）。
- [tableView(_:didSelectRowAt:)](https://developer.apple.com/documentation/uikit/uitableviewdelegate/tableview(_:didselectrowat:))：行がタップされたときに呼ばれるメソッド（2-4）。
- [deselectRow(at:animated:)](https://developer.apple.com/documentation/uikit/uitableview/deselectrow(at:animated:))：行の選択を解除する方法（2-4-1）。
- [navigationController](https://developer.apple.com/documentation/uikit/uiviewcontroller/navigationcontroller)：自分を表示している UINavigationController を取り出すプロパティと、`nil` になる場合（2-4-3、2-5-2、3-6-2）。
- [pushViewController(_:animated:)](https://developer.apple.com/documentation/uikit/uinavigationcontroller/pushviewcontroller(_:animated:))：次の画面をスタックに積んで表示する方法（2-4-3）。
- [popViewController(animated:)](https://developer.apple.com/documentation/uikit/uinavigationcontroller/popviewcontroller(animated:))：いちばん上の画面をスタックから外して、前の画面に戻る方法（3-5-1）。
- [viewControllers](https://developer.apple.com/documentation/uikit/uinavigationcontroller/viewcontrollers)：スタックに積まれている画面の配列（2-5-2、3-6-2）。
- [init(nibName:bundle:)](https://developer.apple.com/documentation/uikit/uiviewcontroller/init(nibname:bundle:))：XIB を使う ViewController をコードで作る方法（3-1）。
- [init(coder:)](https://developer.apple.com/documentation/uikit/uiviewcontroller/init(coder:))：ストーリーボードから画面を作るときに呼ばれるイニシャライザで、サブクラスで書く必要がある理由（3-1）。
- [Initialization（The Swift Programming Language）](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/initialization/)：「Two-Phase Initialization」の節で、サブクラスのプロパティと `super.init` の順番の決まり（説明問題1）。
- [viewDidAppear(_:)](https://developer.apple.com/documentation/uikit/uiviewcontroller/viewdidappear(_:))：画面が表示されたあとに呼ばれるメソッド（2-5、3-6、説明問題2）。
