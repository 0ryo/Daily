# 11/14（土）植物のメモを編集して、再起動しても残す

> 植物の一覧から編集画面へ移り、変えたメモをデリゲートで一覧に返して、ファイルに保存します。

- 作業場所：`1114/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 3時間／パート2 2.5時間
- パート1だけで提出してよいです。

## 守ること
- `!` `try!` `as!` `try?` を使わない（`@IBOutlet` の `!` は除く）
- `plants` を書き換えるのは PlantListViewController だけ。PlantEditViewController は `delegate` で知らせる
- 画面は XIB で作る。SceneDelegate では `PlantListViewController()` で作ってよい
- ブランチ `1114` で PR を作る（マージは不要）

## パート1：編集したメモをデリゲートで一覧に返す（3時間）

### 構造体 `Plant`
育てている植物1つ。パート2でファイルに保存するので、Codable に準拠させます。

| プロパティ | 型 | 意味 |
|---|---|---|
| `name` | String | 植物の名前 |
| `memo` | String | 世話のメモ |

- 型プロパティ：`samples`（[Plant]）。次の3件を、上から順に持つ
  - モンステラ：土が乾いたら水をやる
  - サボテン：月に1回水をやる
  - ポトス：直射日光に当てない

### プロトコル `PlantEditViewControllerDelegate`
編集画面が、保存した植物を知らせる相手の決まり。`AnyObject` に準拠させます。

```swift
func plantEditViewController(_ controller: PlantEditViewController, didSave plant: Plant, at index: Int)
```
- 目的：「保存」で変えた植物を、一覧の何行目かと一緒に知らせる
- 引数：`controller` は知らせる側の画面、`plant` はメモを変えた植物、`index` は一覧の行の番号
- 戻り値：なし

### 画面 `PlantListViewController`
最初の画面。植物を UITableView で一覧にします。

- プロパティ：`plants`（[Plant]。初期値は `Plant.samples`）
- 部品：UITableView

1. **起動したとき**：SceneDelegate で、PlantListViewController を最初の画面にした UINavigationController を window に入れる
2. **`viewDidLoad()`**：`title` を「植物」にする
3. **行を表示するとき**：行に「モンステラ：土が乾いたら水をやる」の形で、名前とメモを出す
4. **行をタップしたとき**：タップした行の植物と行の番号を渡して PlantEditViewController を作り、`delegate` に `self` を入れて push する
5. **`plantEditViewController(_:didSave:at:)`**：`plants` の `index` 番目を受け取った植物にし、UITableView を更新する

### 画面 `PlantEditViewController`
1つの植物のメモを編集する画面です。パート1では、ファイルには書きません。

```swift
init(plant: Plant, index: Int)
```
- 目的：編集する植物と一覧の行の番号を、プロパティ `plant` と `index` に入れ、XIB 名を指定して画面を作る
- 引数：`plant` は編集する植物、`index` は一覧の行の番号
- `init(plant:index:)` を書くと、コンパイラが `init?(coder:)` の追加を求めます

- プロパティ：`plant`（Plant）、`index`（Int）、`delegate`（PlantEditViewControllerDelegate?。`weak var` で宣言する）
- 部品：名前のラベル、メモの入力欄（UITextField）、「保存」ボタン

1. **`viewDidLoad()`**：`title` を「編集」にし、ラベルに植物の名前、入力欄に今のメモを出す。部品に値を入れるのは、`init(plant:index:)` ではなく `viewDidLoad()` にする
2. **「保存」を押したとき**：メモを入力欄の文字列にした植物と `index` を `delegate` に知らせ、pop で PlantListViewController に戻る

### 確かめること
上から順に試し、サボテンのメモを変えて戻った一覧のスクリーンショットを PR に貼ります。

- [ ] 実行する → 「植物」と、モンステラ・サボテン・ポトスの3行が出る
- [ ] 「サボテン」の行をタップする → 編集画面に「サボテン」と「月に1回水をやる」が出る
- [ ] サボテンの編集画面で、メモを「2週間に1回水をやる」にする → 「保存」 → サボテンの行だけが「サボテン：2週間に1回水をやる」に変わる
- [ ] 「ポトス」の行 → メモを書き換える → 「保存」を押さずに左上の戻るボタンで戻る → ポトスの行は「ポトス：直射日光に当てない」のまま

## パート2：メモをファイルに保存して、起動したときに読み込む（2.5時間）

### 構造体 `PlantStore`
植物の一覧を、JSON のファイルに保存して読み込みます。

- プロパティ：`fileURL`（URL。初期値は、Documents ディレクトリの中の `plants.json`。呼び出し側からは渡さない）

```swift
func save(_ plants: [Plant]) throws
```
- 目的：植物の一覧をファイルに保存する
- 引数：`plants` は保存する植物の一覧
- 戻り値：なし。エンコードや書き込みに失敗したときはエラーを投げる

```swift
func load() throws -> [Plant]
```
- 目的：保存した植物の一覧を、保存したときの順番で読み込む
- 引数：なし
- 戻り値：読み込んだ植物の一覧

1. **`fileURL` のファイルがまだないとき**：`Plant.samples` を返す
2. **読み込みやデコードに失敗したとき**：エラーを投げる。空の配列を返さない

### 画面 `PlantListViewController`
- プロパティを変える：`plants` の初期値を `[]` にする
- プロパティを足す：`store`（PlantStore。初期値は `PlantStore()`）

1. **`viewDidLoad()`**：`title` を「植物」にしたあとで、`store.load()` の結果を `plants` に入れる。失敗したときは `title` を「植物（読み込み失敗）」にし、`plants` は `[]` のままにする
2. **`plantEditViewController(_:didSave:at:)`**：UITableView を更新したあとに `store.save(plants)` を呼ぶ。失敗したときは `title` を「植物（保存失敗）」にする

### 確かめること
上から順に試します。読み込みと保存に失敗したときの題名は、確かめなくてよいです。

- [ ] シミュレーターからアプリを削除して実行する → モンステラ・サボテン・ポトスの3行が出る
- [ ] 「モンステラ」のメモを「週に1回水をやる」にして保存 → Xcode でアプリを止めて、もう一度実行する → 3行が同じ順番で出て、モンステラの行が「モンステラ：週に1回水をやる」になっている
