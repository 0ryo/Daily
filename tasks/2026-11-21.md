## パート1：Main.storyboard を使わずに起動し、服の名前を並べる（3時間）

### プロジェクト `WearLog`
アプリ全体の入れ物です。

1. **作るとき**：Xcode で保存先を `apps/` にし、Product Name を `WearLog`、Interface を Storyboard、Language を Swift にした iOS App を作る
2. **作るとき**：「Create Git repository on my Mac」のチェックを外す（リポジトリの中に別のリポジトリを作らないため）
3. **作ったあと**：Main.storyboard とテンプレートの `ViewController.swift` を削除し、Main.storyboard を読み込まずに起動できるようにする

テストのターゲットは、作っても作らなくてもかまいません。

### 列挙型 `ClothingCategory`
服のカテゴリです。case は `tops`（トップス）、`pants`（パンツ）、`outer`（アウター）、`other`（その他）の4つです。

### 構造体 `ClothingItem`
手持ちの服1着です。今日は保存しないので、Codable は不要です。

| プロパティ | 型 | 意味 |
|---|---|---|
| `name` | String | 服の名前 |
| `category` | ClothingCategory | 服のカテゴリ |
| `isReusableBeforeWash` | Bool | 毎回は洗わない服なら `true` |

### 画面 `ItemListViewController`
手持ちの服を一覧で見る、最初の画面です。`UITableViewDataSource` に準拠させ、UITableView の `dataSource` に ItemListViewController をつなぎます。

- プロパティ：`items`（[ClothingItem]。初期値は下の表の5着を、表の上から順に直接書く）
- 部品：UITableView（上下左右を Safe Area に合わせる）

| `name` | `category` | `isReusableBeforeWash` |
|---|---|---|
| 白Tシャツ | `tops` | `false` |
| デニム | `pants` | `true` |
| チノパン | `pants` | `true` |
| ダウンジャケット | `outer` | `true` |
| 靴下 | `other` | `false` |

1. **SceneDelegate の `scene(_:willConnectTo:options:)`**：UIWindowScene から `window` を作り、ItemListViewController を最初の画面にした UINavigationController を `window` の `rootViewController` にして表示する
2. **`viewDidLoad()`**：`title` を「服の一覧」にし、UITableView にセルを登録する
3. **`tableView(_:numberOfRowsInSection:)`**：`items` の数を返す
4. **`tableView(_:cellForRowAt:)`**：セルに、`items[indexPath.row]` の `name` を出す
