## 課題の説明と要件
科目名と勉強した時間（分）を入力して追加すると、一覧に積み上がっていく「勉強時間の記録」アプリを作る。

### モデル
- `StudyRecord`：`subject: String`（科目名）、`minutes: Int`（分）を持つ。
- `StudyLog`：記録の配列（初期値は空）を持つ。配列は外から直接書き換えられないようにする。
- `StudyLog` の `add(subject: String, minutes: Int) -> Bool`
  - 科目名は前後の空白・改行を除去してから判定する。除去後が空でなく、20文字以下なら有効。
  - 分は 1〜600 なら有効。
  - 両方とも有効なら、除去後の科目名で末尾に追加して `true` を返す。どちらかが不正なら配列を変えずに `false` を返す。
- `StudyLog` は、記録の分の合計を返せる。

### 画面（XIB + Auto Layout）
- 部品：科目名の入力欄、時間（分）の入力欄（数字キーボード）、追加ボタン、結果ラベル、合計ラベル、UITableView。
- 起動直後：結果ラベルは「科目名と時間を入力してください」、合計ラベルは「合計：0分」、一覧は0件。
- 追加ボタンを押したとき：
  - 時間の入力は、前後の空白・改行を除去してから Int に変換する。変換に失敗したら追加しない（失敗の扱い）。
  - 成功：一覧の末尾に追加して表示を更新し、両方の入力欄を空にし、キーボードを閉じる。結果ラベルは「追加しました」、合計ラベルを更新する。
  - 失敗：結果ラベルは「科目名と時間を確認してください」。入力欄の内容と一覧は変えない。
- 一覧の各行は「Swift：90分」の形式で表示する。

### 役割と制約
- 検証と追加はモデル（`StudyLog`）が行う。ViewController は入力の取得・時間の文字列から Int への変換・モデルの呼び出し・表示の更新を行う。
- 強制アンラップ（`!`）を使わない（XIB の `@IBOutlet` の宣言は除く）。
- 保存・編集・削除・行タップは不要。
