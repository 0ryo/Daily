## 守ること（パート1・2 共通）
- `!`、`try!`、`as!`、`try?` を使わない（XIB の `@IBOutlet` の宣言の `!` は除く）。
- ライフサイクルの出力（print）は、このあとの関数 1 の `printLifecycle(screen:method:)` を通してだけ行う。HomeViewController と SettingsViewController の中に print を直接書かない。
- ライフサイクルのメソッドを override するときは、メソッドの最初で親クラス（super）の同じメソッドを呼ぶ。
- ブランチを切り、今日の `1104/` の変更だけで PR を作る（マージは不要）。PR の説明に、各テストでコンソールに出た行を貼る。

## パート1：設定の画面を全画面で開いて閉じる（約1.5時間）
### 関数
**1. `printLifecycle(screen: String, method: String)`**（構造体やクラスの外に置く関数。ファイル名は `LifecycleLog.swift`）
- 目的：どの画面のどのライフサイクルのメソッドが呼ばれたかを、決まった形でコンソールに出す。
- 引数：`screen`（String、画面の名前。`"Home"` か `"Settings"`）、`method`（String、呼ばれたメソッドの名前。例：`"viewDidLoad"`）
- 戻り値：なし
- 処理：
  - **1-1.** `printLifecycle` が、`[画面の名前] メソッドの名前` の形の1行を print で出す。例：`screen` が `"Home"`、`method` が `"viewDidLoad"` のとき、`[Home] viewDidLoad` と出す。

### 画面
**2. SettingsViewController**（ホームの画面から開く画面）
- 特記事項：Xcode の「Cocoa Touch Class」で、「Also create XIB file」にチェックを入れて作る。部品は SettingsViewController.xib に置く。
- **2-1. 部品**：「設定」と書いたラベルと、「閉じる」ボタンを置く。
- **2-2. ライフサイクルのメソッド**：次の5つのメソッドを override する。どのメソッドも、super の同じメソッドを呼んだあとに、`printLifecycle(screen:method:)` に `"Settings"` とメソッドの名前を渡す。
  - `viewDidLoad()`
  - `viewWillAppear(_:)`
  - `viewDidAppear(_:)`
  - `viewWillDisappear(_:)`
  - `viewDidDisappear(_:)`
  - `method` に渡す名前は、`"viewDidLoad"`、`"viewWillAppear"` のように、メソッド名から `()` と `(_:)` を除いた文字列にする。
- **2-3. 「閉じる」ボタンを押したとき**
  - **2-3-1.** SettingsViewController が、`dismiss(animated:completion:)` で自分の画面を閉じる。

**3. HomeViewController**（アプリを起動したときに最初に表示する画面）
- 特記事項：SettingsViewController と同じく、XIB（HomeViewController.xib）で作り、部品を XIB に置く。アプリを起動したときに HomeViewController が最初に表示されるように、SceneDelegate.swift で、window の `rootViewController` に HomeViewController を入れる（11/2 の課題の `1102/` で、PlaceViewController を入れたのと同じ設定）。ストーリーボードには部品を置かない。
- **3-1. 部品**：「ホーム」と書いたラベルと、「設定を開く」ボタンを置く。
- **3-2. ライフサイクルのメソッド**：2-2 と同じ5つのメソッドを override する。どのメソッドも、super の同じメソッドを呼んだあとに、`printLifecycle(screen:method:)` に `"Home"` とメソッドの名前を渡す。
- **3-3. 「設定を開く」ボタンを押したとき**
  - **3-3-1.** HomeViewController が、SettingsViewController.xib を使う SettingsViewController を、ボタンを押すたびに新しく作る。
  - **3-3-2.** HomeViewController が、作った SettingsViewController の `modalPresentationStyle` を `.fullScreen` にする。
  - **3-3-3.** HomeViewController が、`present(_:animated:completion:)` で SettingsViewController を表示する。

- 2026-11-04：「override のメソッドの中で printLifecycle を呼ぶところが分からない」と質問があり、HomeViewController.swift と SettingsViewController.swift を読んだ。質問された部分（各 override の中の呼び出し、SettingsViewController の5つのメソッド）は作業中として指摘していない。別の例として viewWillLayoutSubviews / viewDidLayoutSubviews を override して記録関数を呼ぶ例を示した。質問の外で、関数 1 の名前が `printLifeCycle`（HomeViewController.swift:44、課題文は `printLifecycle`）である点と、関数 1 が `LifecycleLog.swift` ではなく HomeViewController.swift に置かれている点を「忘れてない？」として伝えた。
