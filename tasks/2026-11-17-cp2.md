## 課題の説明と要件

### 構造体 `Book`
読んだ本1冊。ファイルに保存するので、Codable に準拠させます。

| プロパティ | 型 | 意味 |
|---|---|---|
| `title` | String | 本の題名 |
| `impression` | String | 感想 |

- 型プロパティ：`samples`（[Book]）。次の3件を、上から順に持つ
  - 星の地図：図が多くて読みやすい
  - 海辺の図書館：最後の章が良かった
  - 雨の日の数学：途中で難しくなった

### プロトコル `BookEditViewControllerDelegate`
編集画面が、保存した本を知らせる相手の決まり。`AnyObject` に準拠させます。

```swift
func bookEditViewController(_ controller: BookEditViewController, didSave book: Book, at index: Int)
```
- 目的：「保存」で変えた本を、一覧の何行目かと一緒に知らせる
- 引数：`controller` は知らせる側の画面、`book` は感想を変えた本、`index` は一覧の行の番号
- 戻り値：なし

### 構造体 `BookStore`
本の一覧を、JSON のファイルに保存して読み込みます。

- プロパティ：`fileURL`（URL。Documents ディレクトリの中の `books.json`。呼び出し側からは渡さない）

```swift
func save(_ books: [Book]) throws
```
- 目的：本の一覧をファイルに保存する
- 引数：`books` は保存する本の一覧
- 戻り値：なし。エンコードや書き込みに失敗したときはエラーを投げる

```swift
func load() throws -> [Book]
```
- 目的：保存した本の一覧を、保存したときの順番で読み込む
- 引数：なし
- 戻り値：読み込んだ本の一覧

1. **`fileURL` のファイルがまだないとき**：`Book.samples` を返す
2. **読み込みやデコードに失敗したとき**：エラーを投げる。空の配列を返さない

### 画面 `BookListViewController`
最初の画面。本を UITableView で一覧にします。

- プロパティ：`books`（[Book]。初期値は `[]`）、`store`（BookStore）
- 部品：UITableView

1. **起動したとき**：SceneDelegate で、BookListViewController を最初の画面にした UINavigationController を window に入れる
2. **`viewDidLoad()`**：`title` を「本」にし、`store.load()` の結果を `books` に入れる。失敗したときは `title` を「本（読み込み失敗）」にし、`books` は `[]` のままにする
3. **行を表示するとき**：行に「星の地図：図が多くて読みやすい」の形で、題名と感想を出す
4. **行をタップしたとき**：タップした行の本と行の番号を渡して BookEditViewController を作り、`delegate` に `self` を入れて push する
5. **`bookEditViewController(_:didSave:at:)`**：`books` の `index` 番目を受け取った本にし、UITableView を更新してから `store.save(books)` を呼ぶ。保存に失敗したときは `title` を「本（保存失敗）」にする

### 画面 `BookEditViewController`
1冊の本の感想を編集する画面です。

- プロパティ：`book`（Book）、`index`（Int）、`delegate`（BookEditViewControllerDelegate?。`weak var` で宣言する）
- 部品：題名のラベル、感想の入力欄（UITextField）、「保存」ボタン、メッセージのラベル

1. **作るとき**：編集する本と一覧の行の番号を受け取る
2. **`viewDidLoad()`**：`title` を「編集」にし、題名のラベルに本の題名、入力欄に今の感想を出す。メッセージのラベルは空にする
3. **「保存」を押したとき**：入力欄の文字列の前後の空白・改行を除去する
   - 除去した後が空なら、メッセージのラベルを「感想を入力してください」にする。`delegate` には知らせず、編集画面に残る
   - 空でなければ、感想を除去した後の文字列に変えた `Book` と `index` を `delegate` に知らせ、pop で BookListViewController に戻る
