# 11/10（火）詳細画面で変えた「読み終えた」を、デリゲートで前の画面に返す
- 作業場所：`1110/`（Xcode の iOS App プロジェクト。XIB + Auto Layout）
- 想定時間：2時間（パート1 約1.5時間、パート2 約30分）
- パート1で、詳細画面のスイッチで決めた「読み終えた」を、デリゲートを使って前の画面に返し、前の画面のラベルに反映します。デリゲートは、ある画面で起きたことを、プロトコルの関数を通して別の画面に知らせる仕組みです。パート2で、詳細画面を開いたときに、スイッチを今の状態に合わせます。パート1が終わった時点で提出してよいです。パート2は、時間がなければ次の日に回してかまいません。

## 守ること（パート1・2 共通）
- `!`、`try!`、`as!`、`try?` を使わない（XIB の `@IBOutlet` の宣言の `!` は除く）。
- プロパティ `book` を書き換えるのは BookViewController だけにする。BookDetailViewController の中では BookViewController の型名を使わず、BookDetailViewController のプロパティ `delegate` を通して知らせる。
- BookViewController と BookDetailViewController は、どちらも XIB で作り、部品を XIB に置く。Main.storyboard には部品を置かない。
- ブランチ `1110` で、今日の `1110/` の変更だけで PR を作る（マージは不要）。

## パート1：詳細画面で決めた「読み終えた」を、デリゲートで前の画面に返す（約1.5時間）
### 構造体
**1. Book**（読みたい本1冊）
- プロパティ：`title`（String、本の題名）、`isFinished`（Bool、読み終えたら `true`）
- 関数：なし
- 特記事項：エンコードとデコードは不要（今日はファイルに保存しない）。

### プロトコル
**2. BookDetailViewControllerDelegate**（BookDetailViewController が、決めた結果を知らせる相手が持つ関数を決める）
- 宣言の形：`protocol BookDetailViewControllerDelegate: AnyObject`
- 関数：
  - **2-1. `bookDetailViewController(_ controller: BookDetailViewController, didSave isFinished: Bool)`**
    - 目的：BookDetailViewController が、「保存」ボタンで決めた「読み終えた」かどうかを、プロパティ `delegate` に入っている相手に知らせる。
    - 引数：`controller`（BookDetailViewController、知らせる側の画面）、`isFinished`（Bool、読み終えたなら `true`）
    - 戻り値：なし
    - 処理：BookDetailViewControllerDelegate の中には処理を書かない。処理は BookViewController の側に書く（3-4）。

### 画面
**3. BookViewController**（1冊の本の状態を表示する、最初の画面。BookViewController.xib）
- プロパティ：`book`（Book、表示する本）
- 部品：本の状態を表示するラベルと、「詳細へ」ボタンを置く。
- **3-1. 起動したとき**
  - **3-1-1.** SceneDelegate.swift の `scene(_:willConnectTo:options:)` で、BookViewController を最初の画面にした UINavigationController を作り、window の `rootViewController` に入れる。
  - **3-1-2.** BookViewController が、`viewDidLoad()` の中で、`title` に「本棚」を入れ、`book` に「坊っちゃん」（`isFinished` は `false`）を入れて、`updateLabel()`（3-2）を呼ぶ。
- **3-2. `updateLabel()`**
  - 目的：`book` の今の状態を、ラベルに表示する。
  - 引数：なし
  - 戻り値：なし
  - 処理：
    - **3-2-1.** `updateLabel` が、`book` の `isFinished` が `true` なら「坊っちゃん：読み終えた」、`false` なら「坊っちゃん：まだ読んでいない」の形で、ラベルに表示する。「坊っちゃん」の部分には `book` の `title` を使う。
- **3-3. 「詳細へ」ボタンを押したとき**
  - **3-3-1.** BookViewController が、XIB の名前「BookDetailViewController」を指定した `init(nibName:bundle:)` で BookDetailViewController を作り、作った BookDetailViewController の `delegate` に自分（`self`）を入れる。
  - **3-3-2.** BookViewController が、自分の `navigationController` の `pushViewController(_:animated:)` で、作った BookDetailViewController を表示する。`animated` は `true` にする。`navigationController` が `nil` のときは何もしない。
- **3-4. `bookDetailViewController(_:didSave:)` が呼ばれたとき**（BookDetailViewControllerDelegate の関数。準拠は extension に書く）
  - **3-4-1.** BookViewController が、`book` の `isFinished` に引数 `isFinished` を入れ、`updateLabel()` を呼ぶ。

**4. BookDetailViewController**（読み終えたかどうかを決める詳細画面。BookDetailViewController.xib）
- プロパティ：`delegate`（BookDetailViewControllerDelegate?、決めた結果を知らせる相手。`weak var` で宣言する）
- 部品：「読み終えた」のラベル、UISwitch、「保存」ボタンを置く。UISwitch は、XIB でオフにしておく。
- **4-1. 「保存」ボタンを押したとき**
  - **4-1-1.** BookDetailViewController が、`delegate` の `bookDetailViewController(_:didSave:)` を、自分（`self`）と UISwitch がオンかどうかを渡して呼ぶ。`delegate` が `nil` のときは呼ばない。
  - **4-1-2.** BookDetailViewController が、自分の `navigationController` の `popViewController(animated:)` で前の画面に戻る。`animated` は `true` にする。`navigationController` が `nil` のときは何もしない。
