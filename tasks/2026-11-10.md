# 11/10（火）読みたい本の一覧で、詳細画面で変えた「読み終えた」を一覧に返す
- 作業場所：`1110/`（Xcode の iOS App プロジェクト。XIB + Auto Layout）
- 想定時間：2時間（パート1 約1.5時間、パート2 約30分）
- パート1で、詳細画面のスイッチで変えた「読み終えた」を、デリゲートを使って一覧の画面に返し、一覧の行に反映します。デリゲートは、ある画面で起きたことを、別の画面にプロトコルの関数を通して知らせる仕組みです。パート2で、詳細画面を開いたときにスイッチを本に合わせ、一覧の画面が受け取った本を print します。パート1が終わった時点で提出してよいです。パート2は、時間がなければ次の日に回してかまいません。

## 守ること（パート1・2 共通）
- `!`、`try!`、`as!`、`try?` を使わない（XIB の `@IBOutlet` の宣言の `!` は除く）。
- 一覧の `books` を書き換えるのは BookListViewController だけにする。BookDetailViewController の中では BookListViewController の型名を使わず、BookDetailViewController のプロパティ `delegate`（4 で作る）を通して知らせる。
- BookListViewController と BookDetailViewController は、どちらも XIB で作り、部品を XIB に置く。Main.storyboard には部品を置かない。
- ブランチ `1110` で、今日の `1110/` の変更だけで PR を作る（マージは不要）。

## パート1：詳細画面で変えた「読み終えた」を、デリゲートで一覧に返す（約1.5時間）
### 構造体
**1. Book**（読みたい本1冊）
- プロパティ：
  - `title`（String、本の題名）
  - `isFinished`（Bool、読み終えたら `true`）
  - `static let samples`（[Book]、一覧に最初に表示する3冊。上から次の順にする）
    - 坊っちゃん（`isFinished` は `false`）
    - 銀河鉄道の夜（`isFinished` は `true`）
    - 走れメロス（`isFinished` は `false`）
- 関数：
  - **1-1. `statusText() -> String`**
    - 目的：読み終えたかどうかを、画面に表示する文字列にする。
    - 引数：なし
    - 戻り値：「読み終えた」または「まだ読んでいない」
    - 処理：
      - **1-1-1.** `statusText` が、`isFinished` が `true` なら「読み終えた」を返し、`false` なら「まだ読んでいない」を返す。
- 特記事項：エンコードとデコードは不要（今日はファイルに保存しない）。

### プロトコル
**2. BookDetailViewControllerDelegate**（BookDetailViewController が、変更した本を知らせる相手が持つ関数を決める）
- 宣言の形：`protocol BookDetailViewControllerDelegate: AnyObject`
- 関数：
  - **2-1. `bookDetailViewController(_ controller: BookDetailViewController, didUpdate book: Book)`**
    - 目的：BookDetailViewController が、変更した本を、プロパティ `delegate`（4 で作る）に入っている相手に知らせる。
    - 引数：`controller`（BookDetailViewController、知らせる側の画面）、`book`（Book、変更したあとの本）
    - 戻り値：なし
    - 処理：BookDetailViewControllerDelegate の中には処理を書かない。処理は BookListViewController の側に書く（3-5）。

### 画面
**3. BookListViewController**（読みたい本の一覧の画面。BookListViewController.xib）
- プロパティ：
  - `books`（[Book]、一覧に表示する本）
  - `selectedRow`（Int?、最後にタップした行の番号。「保存」ボタンで本を受け取ったあとは `nil` に戻す。左上の戻るボタンで戻ったときは変えない）
- **3-1. 部品**：UITableView を1つ置く。
- **3-2. 起動したとき**
  - **3-2-1.** SceneDelegate.swift の `scene(_:willConnectTo:options:)` で、BookListViewController を最初の画面にした UINavigationController を作り、window の `rootViewController` に入れる。
  - **3-2-2.** BookListViewController が、`viewDidLoad()` の中で、`title` に「本棚」を入れる。
  - **3-2-3.** BookListViewController が、`viewDidLoad()` の中で、`books` に `Book.samples` を入れ、一覧に表示する。
- **3-3. 一覧の行**：1行に1冊の本を「坊っちゃん：まだ読んでいない」の形で表示する。「：」の後ろには `statusText()`（1-1）の結果を使う。並び順は `books` の順にする。
- **3-4. 行をタップしたとき**（UITableViewDelegate の `tableView(_:didSelectRowAt:)`）
  - **3-4-1.** BookListViewController が、タップされた行の選択を解除する。
  - **3-4-2.** BookListViewController が、タップされた行の番号を `selectedRow` に入れる。
  - **3-4-3.** BookListViewController が、タップされた行の Book を BookDetailViewController の `init(book:)`（4-1）に渡して、BookDetailViewController を作る。
  - **3-4-4.** BookListViewController が、作った BookDetailViewController の `delegate` に自分（`self`）を入れる。
  - **3-4-5.** BookListViewController が、自分の `navigationController` の `pushViewController(_:animated:)` で、作った BookDetailViewController を表示する。`animated` は `true` にする。`navigationController` が `nil` のときは何もしない。
- **3-5. BookDetailViewControllerDelegate の `bookDetailViewController(_:didUpdate:)`（2-1）が呼ばれたとき**
  - BookListViewController は、BookDetailViewControllerDelegate に準拠する。準拠は extension に書く。
  - 引数 `book` は、2-1 の `book`（変更したあとの本）である。
  - **3-5-1.** `selectedRow` が `nil` のときは、何もしない。
  - **3-5-2.** BookListViewController が、`books` の `selectedRow` の位置の本を、引数 `book` に置き換える。
  - **3-5-3.** BookListViewController が、`selectedRow` を `nil` に戻す。
  - **3-5-4.** BookListViewController が、一覧の表示を `books` に合わせて更新する。

**4. BookDetailViewController**（1冊の本の詳細画面。BookDetailViewController.xib）
- プロパティ：
  - `book`（Book、表示する本。`var` で宣言する）
  - `delegate`（BookDetailViewControllerDelegate?、変更した本を知らせる相手。`weak var` で宣言する）
- **4-1. `init(book: Book)`**
  - 目的：表示する本を受け取って、XIB を使う BookDetailViewController を作る。
  - 引数：`book`（Book、表示する本）
  - 戻り値：なし
  - 処理：
    - **4-1-1.** `init(book:)` が、引数 `book` を、プロパティ `book` に入れる。
    - **4-1-2.** `init(book:)` が、XIB の名前「BookDetailViewController」を指定して、親クラス（UIViewController）の `init(nibName:bundle:)` を呼ぶ。
- **4-2. `required init?(coder: NSCoder)`**
  - 目的：UIViewController のサブクラスに書く必要があるイニシャライザを用意する。今日の課題では、BookDetailViewController をストーリーボードから作らないので使わない。
  - 引数：`coder`（NSCoder、ストーリーボードから画面を作るときに渡されるデータ）
  - 戻り値：なし（失敗できるイニシャライザ）
  - 処理：
    - **4-2-1.** `init?(coder:)` が、`fatalError` を「init(coder:) は使いません」のメッセージで呼ぶ。
- **4-3. 部品**：「読み終えた」のラベル、UISwitch、「保存」ボタンを置く。UISwitch は、XIB でオフにしておく。
- **4-4. 「保存」ボタンを押したとき**
  - **4-4-1.** BookDetailViewController が、`book` の `isFinished` に、UISwitch がオンなら `true`、オフなら `false` を入れる。
  - **4-4-2.** BookDetailViewController が、`delegate` の `bookDetailViewController(_:didUpdate:)`（2-1）を、自分（`self`）と `book` を渡して呼ぶ。`delegate` が `nil` のときは呼ばない。
  - **4-4-3.** BookDetailViewController が、自分の `navigationController` の `popViewController(animated:)` で一覧の画面に戻る。`animated` は `true` にする。`navigationController` が `nil` のときは何もしない。

### 説明問題
