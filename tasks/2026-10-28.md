# 10/28（水）植物の水やり表をファイルに保存して読み戻す
想定 2h ／ 作業場所 `1028.playground/`（リポジトリ直下。`1028/` の中に作ってもよい）
植物の水やり表を JSON のファイルとして保存し、読み戻す型を作ります。画面は作らず、Playground で print して確かめます。

## 必須チェックリスト（完了条件）
1. 植物の型が `name`（String、植物の名前）と `intervalDays`（Int、何日おきに水をやるか）を持ち、エンコードとデコードの両方ができる（JSON のキー名はプロパティ名と同じでよい）。
2. 保存担当が、保存先として Documents ディレクトリの中の `plants.json` の場所を持ち、その場所を外から print できる（一時ディレクトリや、文字列で直接書いたパスにしない）。
3. 保存担当が、植物の配列を JSON にして `.atomic` を指定してファイルに書き込む仕組みと、ファイルを読み込んで植物の配列に戻す仕組みを持つ。
4. 保存・読み込みの失敗を保存担当の中で print して終わらせず、呼び出した側に伝え、呼び出した側が `do`/`catch` で受け取って失敗したこととエラーの内容を print する。
5. 並べ替え問題の関数を、行の追加・削除なしで正しく並べ、テスト #2 で使っている。
6. Playground がエラーなく実行でき、テスト #1〜#6 が期待どおりの結果になり、`!`・`try!`・`as!`・`try?` を使っていない。
7. 型名は大文字始まり、変数名・関数名・プロパティ名は小文字始まりになっている。
8. ブランチを作り、今日の Playground の変更だけを含む PR を作っている（main へのマージは不要）。

## チャットで答える説明（必須）

自由: 植物と保存担当の型名、メソッドの名前・引数・戻り値の形。

## テスト（上から順に実行する。同じ保存担当を使い続ける）
