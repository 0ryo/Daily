# 11/16（月）XIB で、スタンプカードの画面を組む

> スタンプカードの画面を XIB と Auto Layout で組み、横向きにしても部品が切り欠きに重ならないようにします。

- 作業場所：`1116/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 1.5時間／パート2 30分
- パート1だけで提出してよいです。

## 守ること
- `!` `try!` `as!` `try?` を使わない（`@IBOutlet` の `!` は除く）
- 画面は XIB で作る。Main.storyboard には部品を置かない
- 画面の端に対する XIB の制約は Safe Area を基準にする。親ビュー（Superview）の端を基準にしない（部品どうしの間隔は対象外）
- 確かめることは、画面の上に切り欠き（ノッチかダイナミックアイランド）がある iPhone のシミュレータで試す
- ブランチ `1116` で PR を作る（マージは不要）。横向きにしたシミュレータの画面のスクリーンショットを PR に貼る

## パート1：XIB でラベルとボタンを置く（1.5時間）

### 構造体 `StampCard`
スタンプカード1枚の状態です。保存しないので、Codable は不要です。

| プロパティ | 型 | 意味 |
|---|---|---|
| `stampCount` | Int | 押したスタンプの数 |
| `goal` | Int | 特典と交換できるスタンプの数 |

```swift
mutating func addStamp()
```
- 目的：スタンプを1つ押す
- 引数・戻り値：なし

1. **`addStamp()`**：`stampCount` が `goal` より小さいときだけ、`stampCount` を1増やす

### 画面 `StampCardViewController`
スタンプの数を表示し、ボタンでスタンプを押す画面です。

- プロパティ：`card`（StampCard。初期値は `stampCount` が 0、`goal` が 10）
- 部品（XIB）：`countLabel`（UILabel）、「スタンプを押す」ボタン
- XIB の制約：`countLabel` は Safe Area の上端と左右の端から 16。ボタンは `countLabel` の下端から 16 離し、Safe Area の横方向の中央に置く

1. **起動したとき**：SceneDelegate で、`StampCardViewController()` を最初の画面にした UINavigationController を、window の `rootViewController` にする
2. **`updateLabel()`**：`countLabel` を、`stampCount` と `goal` の値で「スタンプ：3 / 10」の形にする
3. **`viewDidLoad()`**：`title` を「スタンプカード」にし、`updateLabel()` を呼ぶ
4. **「スタンプを押す」を押したとき**：`card.addStamp()` を呼び、`updateLabel()` を呼ぶ

### 確かめること
上から順に試します。

- [ ] 実行する → 「スタンプカード」と「スタンプ：0 / 10」が出る
- [ ] 「スタンプを押す」を3回押す → 「スタンプ：3 / 10」になる
- [ ] シミュレータを横向きにする → ラベルとボタンが切り欠きや画面の端に重ならずに出る

## パート2：リセットのボタンを足す（30分）

### 構造体 `StampCard`
```swift
mutating func reset()
```
- 目的：`stampCount` を 0 に戻し、カードを最初からにする（`stampCount` がいくつのときでも戻す）
- 引数・戻り値：なし

### 画面 `StampCardViewController`
- 部品を足す（XIB）：「リセット」ボタン。「スタンプを押す」ボタンの下端から 16 離し、Safe Area の横方向の中央に置く

1. **「リセット」を押したとき**：`card.reset()` を呼び、`updateLabel()` を呼ぶ

### 確かめること
アプリを起動し直して、上から順に試します。

- [ ] 「スタンプを押す」を11回押す → 「スタンプ：10 / 10」のまま増えない
- [ ] 「リセット」を押す → 「スタンプ：0 / 10」に戻る

### 説明問題
シミュレータを横向きにしたとき、Safe Area を基準にした `countLabel` が切り欠きに重ならずに出るのはなぜか？横向きのとき、Safe Area が画面のどの範囲を表すかを含めて答えます。

検索キーワード：`uikit safe area landscape notch`
