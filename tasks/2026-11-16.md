# 11/16（月）コードだけで、スタンプカードの画面を組む

> XIB を使わずに、ラベルとボタンをコードで作って置き、Auto Layout の制約もコードで付けます。

- 作業場所：`1116/`（iOS App・XIB なし）
- 想定時間：パート1 1.5時間／パート2 30分
- パート1だけで提出してよいです。

## 守ること
- `!` `try!` `as!` `try?` を使わない
- XIB を作らない。Main.storyboard に部品を置かない。部品と制約はすべてコードで作る
- 部品の位置は Safe Area を基準にした制約で決める。`frame` で位置を決めない
- 制約の余白には数値を直接書かず、定数 `spacing` を使う
- 確かめることは、画面の上に切り欠き（ノッチかダイナミックアイランド）がある iPhone のシミュレータで試す
- ブランチ `1116` で PR を作る（マージは不要）

## パート1：ラベルとボタンをコードで置く（1.5時間）

### 構造体 `StampCard`
スタンプカード1枚の状態です。保存しないので、Codable は不要です。

| プロパティ | 型 | 意味 |
|---|---|---|
| `stampCount` | Int | 押したスタンプの数 |
| `goal` | Int | 特典と交換できるスタンプの数 |

```swift
mutating func addStamp()
```
- 目的：スタンプを1つ押す
- 引数・戻り値：なし

1. **`addStamp()`**：`stampCount` が `goal` より小さいときだけ、`stampCount` を1増やす

### 画面 `StampCardViewController`
スタンプの数を表示し、ボタンでスタンプを押す画面です。

- プロパティ：`card`（StampCard。初期値は `stampCount` が 0、`goal` が 10）、`spacing`（CGFloat の定数。16）
- 部品：`countLabel`（UILabel）、`stampButton`（UIButton。題名は「スタンプを押す」。題名を、背景色の上で読める文字色にする）。どちらも `private let` のプロパティにする

1. **起動したとき**：SceneDelegate の `scene(_:willConnectTo:options:)` で、`StampCardViewController()` を最初の画面にした UINavigationController を、window の `rootViewController` にする
2. **`viewDidLoad()`**：`title` を「スタンプカード」、背景色を `.systemBackground` にし、`setUpLayout()` と `updateLabel()` を呼ぶ
3. **`setUpLayout()`**：`countLabel` を穴埋め問題のとおりに置く。`stampButton` も `view` に追加し、`countLabel` の下端から `spacing` 離して、Safe Area の横方向の中央に置く
4. **`setUpLayout()`**：`stampButton` を押したときに `stampButtonTapped()` が呼ばれるように登録する
5. **`updateLabel()`**：`countLabel` を、`stampCount` と `goal` の値で「スタンプ：3 / 10」の形にする
6. **`stampButtonTapped()`**：`card.addStamp()` を呼び、`updateLabel()` を呼ぶ

### 穴埋め問題
`setUpLayout()` のうち、`countLabel` を置く部分です。①〜③ を埋めて自分のファイルに書き、続けて `stampButton` の部分を自分で書きます。

- ①：コードで作った部品に、自分で付けた制約だけを使わせる設定
- ②：制約の配列を受け取り、まとめて有効にする型メソッド（型名から書く）
- ③：Safe Area を表すレイアウトガイド

```swift
countLabel.①
view.addSubview(countLabel)

②([
    countLabel.topAnchor.constraint(equalTo: view.③.topAnchor, constant: spacing),
    countLabel.leadingAnchor.constraint(equalTo: view.③.leadingAnchor, constant: spacing),
    countLabel.trailingAnchor.constraint(equalTo: view.③.trailingAnchor, constant: -spacing)
])
```

### 確かめること
上から順に試し、横向きの画面のスクリーンショットを PR に貼ります。

- [ ] 実行する → 「スタンプカード」と「スタンプ：0 / 10」が出る
- [ ] 「スタンプを押す」を3回押す → 「スタンプ：3 / 10」になる
- [ ] シミュレータを横向きにする → ラベルとボタンが切り欠きや画面の端に重ならずに出る

## パート2：リセットのボタンを足す（30分）

### 構造体 `StampCard`
```swift
mutating func reset()
```
- 目的：特典と交換したあと、`stampCount` を 0 に戻してカードを最初からにする
- 引数・戻り値：なし

### 画面 `StampCardViewController`
- 部品を足す：`resetButton`（UIButton。題名は「リセット」。`stampButton` と同じく、題名を読める文字色にし、`private let` のプロパティにする）

1. **`setUpLayout()`**：`resetButton` を `stampButton` の下端から `spacing` 離し、Safe Area の横方向の中央に置く。押したときに `resetButtonTapped()` が呼ばれるように登録する
2. **`resetButtonTapped()`**：`card.reset()` を呼び、`updateLabel()` を呼ぶ

### 確かめること
アプリを起動し直して、上から順に試します。

- [ ] 「スタンプを押す」を11回押す → 「スタンプ：10 / 10」のまま増えない
