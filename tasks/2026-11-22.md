# 11/22（日）服の登録画面を作り、登録した服を一覧に足す

> 一覧の画面から登録画面を開き、入力した服を一覧の最後に足せるようにします。

- 作業場所：`Patim/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 3時間／パート2 1時間
- パート1だけで提出してよいです。
- 今日は要件書の形です。型の分け方、型・関数・プロパティの名前、画面の部品の配置は、自分で決めてください。

## 守ること
- 最新の `patim/main` から `patim/item-register` を切って PR を作り、100点になったら `patim/main` へマージする
- PR の説明に「概要・変更点・確認したこと」を書き、登録画面と、登録したあとの一覧のスクリーンショットを貼る

## パート1：登録画面から一覧に服を足す（3時間）

### 作るもの
ItemListViewController のナビゲーションバーに「追加」ボタンを置きます。「追加」を押すと服の登録画面が開きます。登録画面で名前・カテゴリ・毎回は洗わない服かを入力して「登録」を押すと、登録画面から一覧へ戻り、一覧の最後に服が1行増えます。

### 使うトピック
- UIBarButtonItem：ナビゲーションバーの「追加」ボタン
- UITextField：名前の入力
- UIButton のメニュー（UIMenu・UIAction）：カテゴリの選択（トップス・パンツ・アウター・その他の4つから1つを選び、ボタンの表示が選んだカテゴリの名前になる）
- UISwitch：毎回は洗わない服か
- デリゲート（protocol）：登録した服を登録画面から ItemListViewController に返す

### 条件
- 登録画面の開き方は、push とモーダルのどちらでもよい
- 登録画面を開いた直後は、カテゴリがトップス、スイッチがオフになっている
- 登録画面は、登録した服を protocol のデリゲートで ItemListViewController に返す。登録画面のプロパティに ItemListViewController の型を書かない
- 登録画面は、デリゲートを `weak` のプロパティで持つ
- 登録した服の名前は、前後の空白・改行を除いた名前にする
- カテゴリの選択肢の表示名は、ClothingCategory の `displayName` を使う
- ブランドの入力欄は、置いても置かなくてもよい。置かないときに `brand` へ渡す値も自分で決めてよい（どちらも採点の対象外）

### 確かめること
上から順に試します。

- [ ] 一覧の「追加」を押す → 登録画面が開き、カテゴリがトップス、スイッチがオフになっている
- [ ] 名前に「ニットベスト」と入力し、トップスを選び、スイッチをオンにして「登録」を押す → 一覧へ戻り、一覧の最後に「ニットベスト」が出て、2行目が「トップス・毎回は洗わない」になる
- [ ] もう一度「追加」を押し、名前に「　黒スラックス　」（前後に空白）と入力し、パンツを選び、スイッチをオフにして「登録」を押す → 一覧の最後に、前後の空白がない「黒スラックス」が出て、2行目が「パンツ」になる

## パート2：空の名前を拒否し、キーボードを閉じる（1時間）

### 作るもの
名前が空のまま「登録」を押したときに、登録しないで理由を出します。名前の入力欄で return キーを押すと、キーボードが閉じるようにします。

### 使うトピック
- UILabel：登録できない理由の表示
- UITextFieldDelegate：return キーでキーボードを閉じる

### 条件
- 名前から前後の空白・改行を除くと空になるときは、服を一覧に足さず、登録画面を開いたままにして「名前を入力してください」と表示する
- 名前が空かどうかの判定も、モデルの型に置き、ViewController に書かない
- 登録画面から、登録せずに一覧へ戻れる（モーダルなら「キャンセル」ボタンを置く）

### 確かめること
それぞれ独立に試します。

- [ ] 「追加」を押して登録画面を開く → 名前に空白だけを入力して「登録」を押す → 登録画面のまま「名前を入力してください」が出る
- [ ] 「追加」を押して登録画面を開く → 名前を空のまま「登録」を押す → 登録せずに一覧へ戻る → 一覧の行の数が「追加」を押す前と同じ
- [ ] 「追加」を押して登録画面を開く → 名前の入力欄で return キーを押す → キーボードが閉じる
