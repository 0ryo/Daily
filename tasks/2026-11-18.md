# 11/18（水）キーボードに隠れないメッセージカードの入力画面

> 画面の下に並べた3つの入力欄を、キーボードが出ても隠れないようにし、return キーで次の入力欄へ移れるようにします。

- 作業場所：`1118/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 1.5時間／パート2 30分
- パート1だけで提出してよいです。

## 守ること
- `!` `try!` `as!` `try?` を使わない（`@IBOutlet` の `!` は除く）
- 画面は XIB で作る。Main.storyboard には部品を置かない
- 制約は XIB で付ける。キーボードに合わせて動かすための制約を、コードで足さない
- 提出するときは、1つの部品の同じ辺（上・下・左・右）に、同時に効く制約を2本残さない
- 確かめることは、iPhone のシミュレータでソフトウェアキーボードを出して試す（出ないときは、シミュレータのメニュー I/O > Keyboard > Toggle Software Keyboard）
- ブランチ `1118` で PR を作る（マージは不要）。キーボードを出したシミュレータの画面のスクリーンショットを PR に貼る

## パート1：入力欄をキーボードの上に置く（1.5時間）

### 画面 `MessageCardViewController`
宛名・差出人・メッセージを入力し、カードの文面を `previewLabel` に出す画面です。

- 部品（XIB）：`previewLabel`（UILabel。行数は 0）、`formStackView`（縦向きの UIStackView。間隔 16）
- `formStackView` の中身（上から）：`toField`（プレースホルダー「宛名」）、`fromField`（「差出人」）、`messageField`（「メッセージ」）。3つとも UITextField
- return キーの表示：`toField` と `fromField` は「Next」、`messageField` は「Done」
- XIB の制約：`previewLabel` は Safe Area の上端と左右の端から 16。`formStackView` は Safe Area の左右の端から 16
- XIB の制約：`formStackView` の下端は、Keyboard Layout Guide の上端から 16 上に置く。Keyboard Layout Guide は、XIB の最上位の view を選び、サイズインスペクタで有効にする

1. **起動したとき**：SceneDelegate で、`MessageCardViewController()` を最初の画面にした UINavigationController を、window の `rootViewController` にする
2. **`viewDidLoad()`**：`title` を「メッセージカード」にし、`previewLabel` を「メッセージを入力してください」にする
3. **`textFieldShouldReturn(_:)` で、`toField` の return キーを押したとき**：`fromField` を入力中にする
4. **`textFieldShouldReturn(_:)` で、`fromField` の return キーを押したとき**：`messageField` を入力中にする
5. **`textFieldShouldReturn(_:)` で、`messageField` の return キーを押したとき**：キーボードを閉じ、`previewLabel` を「宛名さんへ：メッセージ（差出人より）」の形にする

### 確かめること
上から順に試します。

- [ ] 実行する → 「メッセージカード」と「メッセージを入力してください」が出る
- [ ] `toField` をタップする → キーボードの上に3つの入力欄がすべて見え、return キーが「Next」（日本語のキーボードでは「次へ」）になる
- [ ] `toField` に「田中」と入れて return キーを押す → カーソルが `fromField` に移り、キーボードは閉じない
- [ ] `fromField` に「佐藤」、`messageField` に「ありがとう！」と入れて return キーを押す → キーボードが閉じ、「田中さんへ：ありがとう！（佐藤より）」が出る

## パート2：制約がぶつかったときのログを読む（30分）

### 画面 `MessageCardViewController`
制約がぶつかったときのログを、わざと出して読みます。

1. **制約を足して `toField` をタップしたとき**：足す制約は、`formStackView` の下端を Safe Area の下端から 16 上に置くもの。コンソールの `Will attempt to recover by breaking constraint` の次の行を PR に貼る
2. **提出する前**：足した制約を消す

### 確かめること
- [ ] 足した制約を消して実行し、`toField` をタップする → コンソールに `Unable to simultaneously satisfy constraints.` が出ない

### 説明問題
`formStackView` の下端に Safe Area の下端への制約を足したとき、起動しただけではログが出ず、`toField` をタップしてキーボードが出たときに初めて `Unable to simultaneously satisfy constraints.` が出るのはなぜか？
