# 11/13（金）ペットの名前を、クロージャで前の画面に返す

> 編集画面で入力したペットの名前を、クロージャで前の画面に返してラベルに出し、編集画面が解放されることを `deinit` で確かめます。

- 作業場所：`1113/`（iOS App・XIB + Auto Layout）
- 想定時間：パート1 1.5時間／パート2 30分
- パート1だけで提出してよいです。
- クロージャは、変数やプロパティに入れて渡せる、名前のない関数です。11/12 はデリゲート（プロトコルの関数）で知らせました。今日は、PetViewController が `onSave` に入れておいたクロージャを、PetNameEditViewController が「保存」のときに呼んで知らせます。

## 守ること
- `!` `try!` `as!` `try?` を使わない（`@IBOutlet` の `!` は除く）
- `petName` を書き換えるのは PetViewController だけ。PetNameEditViewController は `onSave` で知らせる
- 画面は XIB で作る。SceneDelegate では `PetViewController()` で作ってよい
- ブランチ `1113` で PR を作る（マージは不要）

## パート1：名前をクロージャで返す（1.5時間）

### 画面 `PetViewController`
最初の画面。ペットの名前をラベルに出します。

- プロパティ：`petName`（String?。まだ決めていないときは `nil`。初期値は `nil`）
- 部品：名前のラベル、「名前をつける」ボタン

1. **起動したとき**：SceneDelegate で、PetViewController を最初の画面にした UINavigationController を window に入れる
2. **`viewDidLoad()`**：`title` を「ペット」にし、`updateLabel()` を呼ぶ
3. **`updateLabel()`**：`petName` が `nil` なら「ペットの名前：未設定」、`nil` でなければ「ペットの名前：ポチ」の形でラベルに出す。入力欄を空のまま保存したときの表示は決めません
4. **「名前をつける」を押したとき**：`PetNameEditViewController()` で作って定数 `editViewController` に入れ、`onSave` にクロージャを入れて push する。クロージャの中では、`petName` を受け取った名前にし、`updateLabel()` を呼ぶ

### 画面 `PetNameEditViewController`
ペットの名前を入力する編集画面です。

- プロパティ：`onSave`（下の穴埋め問題の ① の型。初期値は `nil`）
- 部品：入力欄（UITextField）、「保存」ボタン

1. **「保存」を押したとき**：入力欄の文字列（`nil` なら空の文字列）を渡して `onSave` を呼び、pop で PetViewController に戻る

### 穴埋め問題
PetViewController と PetNameEditViewController の、クロージャを扱う部分です。下のコードの ①〜③ を埋めて、自分のファイルに書きます。①〜③ の答えはチャットに書かなくてかまいません。

- ①：「String を1つ受け取り、何も返さない関数」の型。`nil` も入れられるようにする
- ②：`onSave` が `nil` かもしれないときの呼び方
- ③：クロージャが PetViewController を弱く参照するように、キャプチャのしかたを決める指定

```swift
// PetNameEditViewController のプロパティ
var onSave: ①

// PetNameEditViewController の「保存」を押したときの処理の中。name は入力欄の文字列
onSave②(name)

// PetViewController の「名前をつける」を押したときの処理の中
editViewController.onSave = { ③ name in
    guard let self else { return }
    // PetViewController の処理4の、クロージャの中身を書く
}
```

### 確かめること
上から順に試し、「ポチ」を保存して戻った画面のスクリーンショットを PR に貼ります。

- [ ] 実行する → 「ペット」と「ペットの名前：未設定」が出る
- [ ] 「名前をつける」 → 「ポチ」と入力 → 「保存」 → ラベルが「ペットの名前：ポチ」に変わる

## パート2：編集画面が解放されることを確かめる（30分）

### 画面 `PetNameEditViewController`
1. **`deinit`**：コンソールに「PetNameEditViewController を解放しました」と出す

### 確かめること
アプリを起動し直して、上から順に試します。「PetNameEditViewController を解放しました」が出たコンソールの出力を、文字のコピーかスクリーンショットで PR に貼ります。

- [ ] 「名前をつける」 → 「タマ」と入力 → 「保存」 → ラベルが「ペットの名前：タマ」に変わり、コンソールに「PetNameEditViewController を解放しました」が出る
