## 課題の説明と要件

### 画面
| 部品 | 要件 |
|---|---|
| 名前の入力欄（UITextField） | プレースホルダーあり。入力中に検証する |
| 名前の状態を示すラベル | 検証の結果に応じて、使えない理由を表示する（文言は自由） |
| 年齢（UIStepper） | 18〜99、初期値20、1ずつ増減 |
| 年齢の表示ラベル | 現在の年齢を常に表示する |
| 通知（UISwitch） | 初期値オフ。ラベルで「通知：オン／オフ」を表示する |
| 登録ボタン | 入力が有効なときだけ押せる。起動直後は押せない |
| 結果ラベル | 登録成功時に内容（名前・年齢・通知）を表示する。初期は未登録を示す文言 |
| 登録済み一覧（UITableView） | 登録済みの会員を、登録した順に1行ずつ表示する |

### モデル（型の分け方と名前は自分で決める）
- 会員1人分の値（名前・年齢・通知可否）を表す型と、登録済みの会員を持つ型を作る。
- 検証と追加の判断はモデル側に置く。画面側は、入力の取得・型の変換・モデルの呼び出し・表示の更新だけを受け持つ。
- 名前の規則：前後の空白・改行を除去した結果が1〜20文字。保存する名前も除去後の値。
- 年齢の規則：18〜99。
- 同じ名前（除去後に同じ文字列）の会員は、二重に登録しない。
- 追加に失敗したときは、登録済みの一覧を変えない。

### 操作
- 名前の入力が変わるたびに（`return` を待たずに）検証し、登録ボタンの有効・無効を更新する。
- ステッパーを動かしたとき、スイッチを切り替えたときも、画面の表示を更新する。
- 登録ボタンで追加に成功したら、一覧を更新し、名前の入力欄を空にし、キーボードを閉じ、年齢とスイッチは初期値に戻す。
- `return` キーでキーボードを閉じる（次の欄への移動は明日の課題なので、今日は不要）。
