# チェックポイント（AIなし課題と人間レビュー）

> この計画が想定する前提：毎月1回、制限時間つきで AI を使わずに解く課題（CP）と、自分以外の人からフィードバックを受ける機会（HR）を設ける。日付は roadmap.md の週区切り（土曜始まり）に合わせており、予定が合わない場合は同じ月の中で動かす。

## AIなし課題（CP）

### 共通のルール
- **使ってよいもの**：Apple の公式ドキュメント、The Swift Programming Language、Xcode の通常のコード補完。
- **使ってはいけないもの**：AI（Claude Code、ChatGPT、Xcode のコーディングアシスタントと予測補完。始める前に Xcode の設定で無効にする）、過去の自分のコード、Web 検索で見つけたコード例。
- 課題文は CP の当日に先生役が出す。開始と終了の時刻を記録し、時間切れの時点のコードを提出する（時間外の修正は採点しない）。
- 置き場所は `CP1/`〜`CP6/`（作成前に承認を得る）。
- 採点は rubric.md で行い、合格の条件も rubric.md に従う。不合格の場合は、2週間以内に同じ範囲の類題を再度 AI なしで解く。

| CP | 週 | 日付 | 制限時間 | 範囲 | 出題の形（例） |
|---|---|---|---|---|---|
| CP1 | 2 | 2026-10-25（日） | 90分 | UIKit の1画面、入力検証、一覧（XIB 可） | 入力欄2つと一覧を持つ画面。不正な入力を拒否し、追加した内容を UITableView に表示する |
| CP2 | 5 | 2026-11-15（日） | 120分 | 画面遷移、デリゲート、Codable 保存 | 一覧 → 詳細 → 編集。編集結果をデリゲートで返し、再起動後も残す |
| CP3 | 9 | 2026-12-12（土） | 150分 | MVVM、async/await、ユニットテスト | 公開 API の結果を一覧表示し、読み込み中・失敗・再試行を表示する。ViewModel のテストを書く |
| CP4 | 15 | 2027-01-23（土） | 150分 | UIKit の総合（XIB なし） | コードだけで、Diffable と Compositional Layout の一覧と詳細への遷移を作る。画面を閉じたとき VC が解放される |
| CP5 | 18 | 2027-02-13（土） | 150分 | SwiftUI の基礎 | `List`・`NavigationStack`・`@Observable`・入力検証つきの `Form` で、一覧・追加・編集を作る |
| CP6 | 23 | 2027-03-20（土） | 180分 | 総合（SwiftUI・SwiftData・相互運用） | SwiftData で保存する SwiftUI の画面を作り、UIKit の画面から UIHostingController で開く。テストを含む |

## 人間レビュー（HR）

### 共通のルール
- 自分以外の人間から、コード・設計・成果物について1件以上の具体的なフィードバックをもらうことを達成条件とする。
- もらったフィードバックは GitHub の Issue にし、対応したかどうかを記録する。
- 勉強会は connpass などで、iOS・Swift のオンラインまたは近場のイベントを探す。

| HR | 週 | 時期 | 形式 | 達成条件 |
|---|---|---|---|---|
| HR1 | 2〜3 | 2026年10月下旬 | iOS・Swift の勉強会（もくもく会でも可）に参加する | 自分の課題のコード（例：単元4の統合課題）について質問し、1件以上のコメントをもらう |
| HR2 | 7 | 2026年12月3日 | OSS への PR（1件目） | ドキュメントの誤り・サンプルの不具合など小さな修正の PR を提出し、メンテナーの反応を記録する |
| HR3 | 9 | 2026年12月17日 | App1 の設計レビュー | 要件定義・画面遷移図・データモデルを勉強会・知人・入社先の窓口などに見せ、指摘を Issue にする |
| HR4 | 14 | 2027年1月18日 | App1 のユーザーテスト | App Store 版を3人以上に使ってもらい、感想を Issue にする |
| HR5 | 19 | 2027年2月24日 | OSS への PR（2件目） | コードの変更（不具合の修正、テストの追加など）を含む PR を提出する |
| HR6 | 23 | 2027年3月25日 | LT、または入社先の担当者への成果物の共有 | 「UIKit アプリに SwiftUI を段階導入した話」などを5分で発表し、質問や感想を1件以上もらう |

## 記録のしかた
各 CP・HR のあと、週の振り返りに次の3点を書く。
1. 結果（点数、または得られたフィードバック）
2. 時間内にできなかったこと、または指摘されたこと
3. 次の2週間で直すこと
