# Swift Daily

iOS エンジニアを目指して、Swift / UIKit / SwiftUI を毎日コツコツ勉強しているリポジトリです。
AI（Claude Code）を「答えを書いてくれる相手」ではなく、**課題を出して採点してくれる先生**として使っています。

## なぜ AI を先生にしているのか
AI にコードを書かせると、早く動くものはできても、自分の力にはなりません。
そこでこのリポジトリでは役割を分けています。

- **自分**：毎日の課題を、自分の手で実装する。
- **AI**：その日の課題を出す、提出したコードを採点する、つまずいたときに考え方や公式ドキュメントを教える。

AI には「解答のコードは書かない」「直し方を答えとして教えない」というルールを設定しています。
自分で調べて、自分で直す流れを毎日くり返すことが目的です。

## 1日の流れ
1. AI に「今日の課題を作成してください」と頼む。進み具合と苦手なところを踏まえた課題が出ます。
2. 課題を自分で実装して、コミットする。
3. 「できました」と伝える。AI が完了条件とルーブリック（採点基準）に沿って採点し、良かった点と直すべき点を返します。
4. 必須の条件が満たせていなければ、自分で直して再提出する。

このほかに、週末に1週間の振り返りをして翌週の目標を決めます。
月に1回は、AI を一切使わずに時間内で課題を解くテストで、本当に身についたかを確かめています。

## リポジトリの中身
| 場所 | 中身 |
|---|---|
| `MMDD/`、`MMDD.playground/` | 毎日の課題で書いたコード（Xcode プロジェクトや Playground） |
| `tasks/` | 出された課題文 |
| `reviews/` | 提出したコードの採点結果 |
| `progress/` | 学習ログ、週ごとの振り返り、苦手なところのまとめ |
| `plan/` | 学習の目標と、採点基準 |
| `.claude/`、`CLAUDE.md` | AI を先生役として動かすための設定 |

## 学んでいること

- Swift の言語機能（Codable、エラー処理、非同期処理など）
