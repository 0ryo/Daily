# Swift Daily

## 毎日の使い方
このリポジトリでは、Claude Code を先生役（出題・進度管理・評価だけ）として使います。毎日は次の2つの言葉だけで進めます。

| 言うこと | 先生役がすること | コマンド |
|---|---|---|
| **「今日の課題を作成してください」** | 今週の計画と記録を読み、今日の課題を `tasks/YYYY-MM-DD.md` に作って表示する | `/today` |
| **「できました」** | 課題の基準コミットからの差分を読み、ルーブリックで採点して `reviews/` と `progress/log.md` に記録する | `/done` |

- 「今日の課題ちょうだい」「終わった」「できた」などの言い回しでも動きます。
- 週末は `/week`（振り返り）、月1回は `/test-noai`（AIなし課題）、弱点の確認は `/weakness` を使います。
- 課題を作る前に、学習用コードの未コミットの変更をコミットしておきます。
- 先生役は学習用コードを書きません。直し方も示しません。

## 構成
- `plan/`：長期・中期の目標（`goals.md`）、週ごとの短期目標（`short-term/`）、求人要件との対応表、ルーブリック、チェックポイント。`archive/` は 2026-10-24 までの24週計画（参照しない）
- `tasks/`・`reviews/`・`progress/`：課題、レビュー、学習ログ、週の振り返り、弱点の記録
- `MMDD/`、`MMDD.playground/`：毎日の課題のコード。今後は `CP1/`〜`CP6/`（AIなし課題）、`apps/`（成果物アプリ）も置く
- `.claude/`：先生役のスキル、レビュー用サブエージェント、学習用コードへの書き込みを止めるフック
- `studyplan/`：2026-10-16 までの旧計画（記録として残している）
